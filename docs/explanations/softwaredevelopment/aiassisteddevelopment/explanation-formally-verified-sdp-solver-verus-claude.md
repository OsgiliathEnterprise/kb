# Formally Verified Semidefinite Programming — Claude-Generated Verus Proofs for a Hand-Written Rust SDP Solver

## Overview
Perry Hart, *"Formally Verified Semidefinite Programming"* (arXiv:2611.25174, Nov 2026, 9 pages; cs.SE / cs.LO / math.OC, CC-BY 4.0) presents a **formally verified Rust implementation of a first-order semidefinite programming (SDP) solver** — a nontrivial piece of numerical software. The division of labor is the headline result: the authors **wrote the solver by hand** and then **directed Claude to generate the entire verification in Verus**, an automated theorem prover for Rust programs.

## Problem Statement
Numerical optimization software is rarely machine-checked: verified SDP solvers essentially did not exist. And if a correctness proof is AI-generated, the guarantee must come from the checker, not from trust in the model that produced the proof.

## Approach
- **Solver:** first-order SDP algorithm, implemented by hand in Rust.
- **Proof:** the *entire* verification generated by the Claude AI coding agent, checked in the **Verus** toolchain (SMT-backed verification for safe Rust — traits, refinement types, and ghost code let specifications sit next to executable code).
- **Discussion:** the paper covers the underlying algorithm, the Rust implementation, and the **pragmatic approach to proving it correct in Verus** — the iterative loop of decomposing lemmas, feeding counterexamples/errors back to the agent, and having a human steer the proof strategy rather than hand-write proofs.

## Why It Matters
- **Trust shifts from author to checker:** an AI agent can produce the whole proof as long as Verus accepts it; the human role becomes specifying *what* is proved and auditing proof structure.
- **Verified scientific computing:** a machine-checked SDP solver opens the door to certified numerical evidence in optimization-heavy fields (control, quantum information, combinatorial bounds).
- **Reusable pattern for AI-assisted formalization:** hand-written implementation + agent-generated specification/proof + verifier-as-arbiter is a template that generalizes beyond SDP to other critical numerical code.
