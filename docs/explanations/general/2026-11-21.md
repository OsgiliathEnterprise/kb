### Serious cyberattack on Iceland's dominant web host 1984 — "well-funded attackers"
1984 ehf., which hosts a large share of all Icelandic websites plus email and DNS for tens of thousands of customers, shut down **all** services after a cyberattack its managing director calls unprecedented — executed "at a speed unlike anything anyone has ever heard of" and likely costing the attackers "tens of millions in AI costs." Front-end services were targeted; CERT-IS and the Icelandic Electronic Communications Office are investigating, with no confirmed attribution yet. A stark example of AI-accelerated attack tooling against critical hosting infrastructure.

### CocoaPods trunk goes permanently read-only on 2 December — audit your Flutter/iOS apps
From Dec 2, 2026 no new pods or pod versions can be published: existing builds keep working, but security fixes and Apple-compat patches can no longer reach you through CocoaPods — a "slow freeze," not a crash. Firebase already left (13.0.0 is SPM-only; CocoaPods pinned at 12.19.x). The article gives a 10-minute audit: upgrade to Flutter ≥3.44, read the SPM plugin warnings, inspect `ios/Podfile.lock`, replace CocoaPods-only plugins, then `pod deintegrate` and remove Podfile/Pods/.symlinks. One CocoaPods-only plugin keeps the whole fallback alive — start now.
Source: [DEV.to](https://dev.to/israr-kundi/cocoapods-read-only-2-december-check-your-flutter-app-491b)

### Cilium HostFirewall is disabled by default — your nodes may be wide open
`hostFirewall.enabled` defaults to `false` in Cilium's Helm chart, so host-endpoint policies silently do nothing while pod policies look fine — broad node-to-node, management- and workload-network traffic remains. The walkthrough covers inventorying the node boundary, using audit mode as a *bounded* migration step (it doesn't survive agent restarts and isn't enforcement), the known first-enforcement reply-traffic drop, hostNetwork pod caveats, and out-of-band recovery before you firewall yourself out of the node.

### Replacing a $1,200/yr fitment API with static JSON + an MCP server
A wheel store swapped three sequential proxied REST calls (600ms+ p95, vendor outages = dead storefront) for a ~13,000-vehicle minified JSON at the Cloudflare edge — smaller than one hero JPEG — plus an open-source MCP server exposing deterministic offset/backspacing/PCD calculators so LLMs stop hallucinating center bores. Good general pattern: deterministic data + deterministic math tools beat "ask the model" and recurring API rent. Limitations covered: trim/brake exceptions, niche catalogs, LCP impact.
Source: [DEV.to](https://dev.to/fatt/replacing-a-1200yr-wheel-fitment-api-with-a-static-json-file-and-an-mcp-server-107k)
