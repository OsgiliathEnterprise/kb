# Beyond Trust in AI-Generated Proofs: Formally Verified Semidefinite Programming for Quantum Correlations

## Overview
This work tackles the weakest link in formally verified numerical software: **the proof itself**. Verifying a solver is only as strong as the mathematical proof of its correctness — and proofs are exactly the kind of large, formal artifacts where AI generation invites distrust. The authors deliver, for the first time, a **formally verified semidefinite programming (SDP) solver**: a hand-written Rust implementation whose *entire* proof of correctness was generated by the Claude AI coding agent.

## Problem Statement
Numerical results used as evidence in **mathematics and physics** — here, quantum-correlation bounds — need more than passing tests; they need machine-checked guarantees that the solver's output is correct. Two gaps stand in the way:
1. Verified numerical optimization software is scarce, especially for SDP.
2. If correctness proofs are (partly) AI-generated, how can we trust the artifact "beyond trust" in the model that produced the proof?

## Approach
- **Solver:** a semidefinite programming solver implemented by hand in Rust.
- **Proof:** the full correctness proof is written in the **Verus** verification toolchain and was generated by the **Claude** AI agent.
- **Application:** the verified solver computes bounds on **quantum correlations**, i.e. numerical results that feed physics/mathematical arguments.
- The paper discusses the algorithms involved, implementation details, and the pragmatic approaches needed to make AI-generated Verus proofs tractable (proof decomposition, iteration against the verifier, human review of proof structure rather than line-by-line authorship).

## Why It Matters
- **A new trust regime for AI-generated proofs:** the machine checker, not the author's reputation, is the guarantee. An AI agent can produce the proof as long as Verus accepts it — shifting the human role to specifying and auditing *what* is proved.
- **Verified scientific computing:** first verified SDP solver opens the door to machine-checked numerical evidence in quantum information and beyond.
- **AI-assisted development signal:** the paper's title framing — "beyond trust in AI-generated proofs" — captures a practical pattern: use AI for the laborious formalization layer while keeping the implementation and specification human-controlled.
