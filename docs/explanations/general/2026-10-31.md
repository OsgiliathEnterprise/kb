### 2. Backdoored "official" Claude Code VS Code extension on the Cursor Marketplace
A tampered copy of the official Claude Code for VS Code extension (versions **2.1.312 / 2.1.313**) sat in the Cursor marketplace for ~11 hours, downloaded by "at most 5,000 users". Per [Phorion](https://phorion.io/blog/offical-claude-code-vsx-compromise/), it drops a persistent SSH backdoor (Ed25519 key `svc-telemetry` in `~/.ssh/authorized_keys`, launchd/cron/Windows scheduled-task persistence, recon beacons) across macOS/Linux/Windows; a bug in the macOS SSH-enable logic limited full compromise on most machines. [Anthropic confirmed](https://www.wired.com/story/trojan-malware-targets-thousands-of-anthropic-claude-developer-systems/) the tampered copy was published via access to Cursor's marketplace and was not built by Anthropic — official channels are unaffected, but [Cursor has published](https://cursor.com/blog/claude-code-extension-security-notice) remediation steps: check for the affected versions and engage IR if found.

### 3. Northflank security incident: assume ALL environment variables are decrypted
Northflank's [status page](https://status.northflank.com) declares a major security incident: assume all env vars (workloads, secret groups, global secrets) have been decrypted and rotate everything immediately. Multiple customers confirmed unauthorised use of AI API keys stored on the platform — consistent with the broader "Black October" pattern Wiz documented against AI developer platforms. Audit logs have been enabled for all customers, incl. free tier.

### 4. 333 Tor exit nodes hijacked for mass surveillance and SSH key theft
An attacker compromised ~10% of the network's total exit capacity (~333 nodes) via a reused password on a Tor management server, installing the **Ebury Linux backdoor** on already-quietly-infected legitimate nodes. From Oct 2, SSH (port 22) traffic was redirected through 12 interception servers running Paramiko-based scripts to steal remote credentials, while encrypted mail ports were blocked to force plaintext downgrades ([Developpez](https://securite.developpez.com/actu/388580/Un-pirate-parvient-a-compromettre-et-a-detourner-333-noeuds-de-sortie-Tor-a-des-fins-d-espionnage-de-masse-et-de-vol-de-cles-d-acces-SSH-L-initiative-bouscule-certaines-certitudes-sur-ce-reseau/)). Discovered by a Swiss engineer and quickly neutralised by the Tor Project — a stark reminder that Tor anonymity does not automatically secure the connections you make through it.

### 5. Scribd breached (Tell HN)
[HN thread](https://news.ycombinator.com/item?id=50312756): users received incident notices (via Epiq, Oct 26) saying a third party accessed email addresses plus credit-card last-4, issuer, expiry date and payment history. No evidence of misuse yet; law enforcement and DPAs notified, affected systems secured.

### 4. JDK 27: G1 becomes the default garbage collector in all environments
[inside.java](https://inside.java/2026/10/30/jdk27-gc-changes/): JEP 523 makes G1 the default everywhere (no Serial fallback; Serial still available via `-XX:+UseSerialGC`). Also: `MinHeapFreeRatio`/`MaxHeapFreeRatio` now default to 0/100 (ending post-full-GC heap resizing churn), improved adaptive concurrent marking, better TLAB sizing for many short-lived threads, and ~350 GC changes overall.

### 5. Azure's Weakest Link (part 3): five more full cross-tenant compromises
[Binary Security](https://www.binarysecurity.no/posts/2026/10/one-root-case): five critical EoP bugs in **Azure API Connections** (Logic Apps). By abusing ARM `DynamicInvoke`/`/extensions/proxy/` endpoints and validation-before-normalisation flaws, any tenant can drive a victim's connection to use the victim's token against the victim's backend — full access to Key Vaults, Azure SQL, Jira, Salesforce, etc. Netted a $200K bounty; all fixed.

### 6. Anthropic drops Claude's five-hour session cap (Ultra), rebrands plans

Weekly caps unchanged (Ultra = 10× Pro); each plan now bundles API credits equal to the subscription price.

### 7. GPT-6.1 Terra vs GPT-6 Astra: cheap-and-fast loses on accuracy
[The New Stack](https://thenewstack.io/gpt-6-1-terra-vs-gpt-6-astra/): Terra (Oct 26) is priced at $1/$5 per M tokens — a tenth of Astra's $10/$50 — and runs ~3× faster on Agents' Last Exam. In TNS's three synthetic tests Terra was faster and far cheaper (31.4s/$0.25 vs 145s/$3.01 on one task) but scored **26/50 vs 48/50** on data work, produced off-by-one counts with the same confidence, and in one case "handed the work back" (returned SQL to run instead of answers); on the rule-audit task it hit 100% precision but missed 5 invalid records, while Astra caught all 40 at ~12× the cost.
