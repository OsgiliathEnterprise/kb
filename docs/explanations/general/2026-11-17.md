## 🔴 P0 - Critical

### Optimizely compromised: malware served to Zoom, BBC, CNN, GitLab, HSBC and 170+ more
Attackers gained write access to the "Project JavaScript" field of ~178 customer projects on the Optimizely Web experimentation platform and injected a multi-purpose malware kit served from the trusted `cdn.optimizely.com` domain. The payload clipped crypto wallets, skimmed payment cards, stole cookies/screenshots, and delivered Coruna/DarkSword iOS exploit kits; verified crypto theft already occurred. The injection vector (how the attacker got cross-customer write access) is still unexplained — a textbook third-party supply-chain compromise that CSP enforcement and script-monitoring would have caught.
Source: https://blog.report-uri.com/worlds-largest-brands-infected-with-malware-via-optimizely/

### Google/Mandiant: autonomous AI agents now turn security patches into exploits
Google's Threat Intelligence Group and Mandiant reported the first observed cases of attackers fully automating vulnerability discovery and exploitation with LLM agent frameworks (an orchestrator plus specialized agents wired via MCP). One exposed staging server ran an `exploit_agent` doing patch diffing → exploit generation → attempted execution with no human approval; other frameworks (CAIRN, CyberStrikeAI, HexStrike) automate 100+ security tools. Attackers are moving from patch disclosure to working exploit in minutes, collapsing the patch window — though current agents are noisy, hallucinate targets, and trade stealth for velocity.
Source: https://thenewstack.io/autonomous-ai-exploit-agents/

### Microsoft 365 global outage traced to a hidden Windows bug; real-world safety impact
Microsoft revealed that a hidden Windows bug triggered the worldwide Microsoft 365 service outage, with cascading failures. In one alarming follow-up, a hotel's email-based chlorine-gas alerting system failed during the M365 outage: 15 guests were hospitalized from chlorine exposure, 40 responders were deployed. A strong case study for not letting safety-critical alert paths depend on a single SaaS provider.
Sources: https://microsoft.developpez.com/actu/389145/ · https://microsoft.developpez.com/actu/389116/

### Windows 11 is telemetry-ing which coding agents and dev tools you use
Reverse engineering of `MissionControlAggregator.dll` found explicit matching of `codex.exe`, `claude.exe`, `copilot.exe`, `cursor.exe`, `agy.exe`, `antigravity.exe` plus dev tools (node, python, dotnet, gcc, clang, gdb, javac, devenv, code) — including WSL routes and publisher checks. Usage bits feed a diagnostic ETW report uploaded to Microsoft unless you disable "optional diagnostic data" (on by default). Fix: Settings → Privacy & security → Diagnostics & feedback → turn off "Send optional diagnostic data".
Source: https://xusheng.dev/posts/windows-coding-agent-telemetry/

### kube-proxy IPVS backend: removal scheduled for Kubernetes 1.40
SIG Network formally scheduled removal of the `ipvs` backend (deprecated in 1.35) in Kubernetes 1.40. IPVS never reached full Service-API compatibility and the kernel IPVS API lacks batch updates; the `nftables` backend (GA since 1.33) is the intended successor for everyone. Migration is mostly a kube-proxy config change (reboot nodes when switching to `iptables`). IPVS users should plan the migration now.
Source: https://kubernetes.io/blog/2026/11/16/ipvs-removal/
