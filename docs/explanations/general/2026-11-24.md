### Everest Forms file deletion is a recovery problem, not only a patch
Two CVEs in the WordPress Everest Forms plugin (CVE-2026-129024, CVE-2026-131750) allow file deletion — and the author's point is that patching alone misses the blast radius: deletion-attack CVEs need backup integrity checks, deletion-source forensics, and a recovery runbook, because the patch stops the bleeding but doesn't restore what's already gone. ### OpenAI + Cisco open-source Shirudo: eBPF shields for unpatched Linux
Shirudo (Japanese for "shield") is an open-source runtime that blocks exploitation of *running* Linux systems while patches are being built: a guardian agent generates targeted eBPF shields, tests them in monitor mode against real traffic and exploit replay, humans approve, shields load cryptographically signed through the eBPF verifier, and a TPM records what's loaded. The proof point: a Codex-generated shield blocked a Java4Shell exploit against a live Elasticsearch with no restart (Isovalent-controlled test). BSD-2 licensed; roadmap goal is shipping tested shields alongside CVE disclosures. KB note written.
Source: [OpenAI](https://openai.com/index/introducing-shirudo/)

### Kubernetes v1.38 sneak peek: two breaking changes to plan for before Dec 16
Release planned 2026-12-16. Breaking: (1) container runtimes must report the cgroup driver via the CRI `RuntimeConfig` RPC *before kubelet starts* — the kubelet `cgroupDriver` field is rejected unless the temporary `LegacyCgroupDriverFallback` gate is on, kubeadm drops its `systemd` default, and kubelet exits if it can't query the runtime; (2) on `LimitedSwap` nodes, pods with pod-level memory request == limit get **zero swap**, containers included. Also: `KUBECTL_REMOTE_COMMAND_WEBSOCKETS`/`KUBECTL_PORT_FORWARD_WEBSOCKETS` env vars removed, kuberc allowlist `name` field dropped, and kuberc/pod-level-resources/DRA-partitionable-devices go GA. KB note written with an upgrade checklist.
Source: [kubernetes.io blog](https://kubernetes.io/blog/2026/11/23/kubernetes-v1-38-sneak-peek/)

### Z.ai GLM-5.4: the first production Loop Transformer
GLM-5.4 runs a shared block of 28 layers **twice** at inference — depth without extra parameters. The engineering: per-token gates keep residual norms stable across iterations, iteration 2 shares the first pass's KV cache plus a separate sliding window (keeping 1M-token context affordable), sparse attention indices are reused, and fused kernels cut memory traffic. Published 30B-scale results beat a same-size conventional transformer on math/science/long-context at ~10% more training compute with 10–14% fewer output tokens. The headline claim (750B rivals 2–3T models) has **no published full benchmarks** — treat as vendor claim. KB note written.
Source: [The New Stack](https://thenewstack.io/zai-glm54-loop-transformer/)

### Stalwart 1.2.0 is now a drop-in Microsoft Exchange replacement
The Rust mail suite now implements MAPI over HTTP, EWS, Exchange ActiveSync and Autodiscover in the AGPL community edition — classic Outlook keeps working, rules become Sieve at delivery, delegates become Stalwart shares. The timing is Microsoft's converging exits: Exchange 2016/19 support ended Oct 2025 (ESU ended Oct 2026), Subscription Edition is the last on-prem version, and EWS in Exchange Online starts switching off this month. Gaps to check before migrating: no public folders, no archive mailboxes, no NTLM/Kerberos. And beware the New Outlook IMAP loophole — it relays your credentials and mail through Microsoft's cloud, defeating the sovereignty argument. KB note written.
Source: [Stalwart blog](https://stalw.art/blog/microsoft-exchange-replacement/)
