📰 Daily News Digest - 2026-11-18

Scanned 13 feeds, 29 unread articles.

🔴 P0 - Critical​

Java4Shell: critical OpenJDK RCE (CVE-2026-114938, CVSS v4.0 9.2)​

A memory-corruption bug in the x86-64 intrinsic implementation of OpenJDK's Base64 decoder allows a heap out-of-bounds write (miscalculated store mask on padded input with a stray =), enabling Heartbleed-style heap disclosure and remote code execution. Any application decoding externally supplied Base64 is potentially affected; reportedly exploitable without authentication in some products. Affects OpenJDK/Java SE 17.x, 21.x, 25.x, 27.x on CPUs with AVX-512 VBMI (ARM64 unaffected); fixed in 17.0.21.1, 21.0.13.1, 25.0.5.1, 27.0.1.1, with mitigations -XX:-UseBASE64Intrinsics or -XX:UseAVX=2. Patch internet-facing JVMs urgently. Source: JFrog Security Research (via This Week in Spring)

Microsoft's ONNX Runtime has disappeared from GitHub​

The main microsoft/onnxruntime repo (22k stars) and at least seven related repos return 404 with no advance warning or official explanation — verified personally; source builds and CI pipelines that clone from GitHub are breaking, while pip/NuGet/Maven packages still install. Community theories range from a security disclosure (a March 2026 parser flaw allowing arbitrary file/memory reads via crafted ONNX models was cited in discussion) to a GitHub outage; mirrors (intel fork, SourceForge, syntax-syndicate fork) are circulating but their trustworthiness is unverified — pin cached artifacts and avoid random forks until Microsoft speaks. Source: GitHub · RuntimeWire report

🟠 P1 - Important​

DuckDB 2.0 "Cinnamon Teal": client-server mode and Agent Mode​

DuckDB's biggest release ever (first major since 1.0.0 two years ago) ships the Quack remote protocol as a first-class citizen for networked operation, enables the extensible SQL parser by default, and adds a dedicated Agent Mode with machine-readable JSON errors, no hidden truncation, and runaway-query guardrails for coding agents (Claude Code, Codex, Cursor). The storage format is deliberately broken for compatibility — DuckLabs' own head of DevRel urges not running a .0 release in production and to wait for the imminent 2.0.1. Source: The New Stack

Cerebras launches disaggregated inference in production​

GPUs handle prompt processing (prefill) while Cerebras Wafer Scale Engines handle autoregressive decode, where their tens of GB of on-chip SRAM and ~5,400× the memory bandwidth of a GB300 GPU give a decisive advantage. Now in production, delivering 5× more tokens per megawatt at Cerebras' ultrafast speeds, offered both via the Inference Cloud and to infrastructure partners — key economics against a projected 24× inference-demand growth to 2030 vs 2.2× datacenter capacity. Source: Cerebras blog

OpenAI launches ChatGPT Wallet for agentic purchases​

Launched Nov 13 with American Express, Chase, Mastercard and Visa, ChatGPT Wallet lets OpenAI's always-on "dots" agents complete purchases through merchants' existing payment rails, with spending limits by amount, category, and time; merchants keep control of pricing, fulfillment, returns. Currently limited to select US ChatGPT Pro subscribers — a significant step in agent-driven commerce, racing Visa's Intelligent Commerce Connect and similar network initiatives. Source: Developpez

Harvard: AI coding agents shifted the bottleneck to code review​

A working paper (Chen & Stratton, Harvard; Jellyfish + Revelio data across 718 firms, ~726k workers) finds engineers at AI-agent adopters added ~30% more code, yet finished work did not measurably rise and code review took 49% longer. Caveats: job-market paper, not peer-reviewed. Practical takeaway for teams adopting coding agents: measure approved work product, revision rates, and reviewer time — not drafting output. Source: ComplexDiscovery

Google's AI Overviews cut outbound clicks by ~40%​

A randomized experiment (Agarwal & Sen, Jan–Feb 2026) hiding AI Overviews from some US desktop users shows Overviews remove ~40% of clicks to outside websites. AI Overviews now appear on 61.4% of tracked US keywords (up from 5.9% in Sept 2024); GEO offers little compensation — AI assistants sent sites just ~0.3% of traffic. Material for anyone with SEO-dependent content strategy. Source: RevScope

🟡 P2 - Interesting​

Senate hearing slams Roblox over child sexual abuse​

Grooming survivors testified before a Congressional subcommittee; ~200 lawsuits are pending against Roblox, and CEO Baszucki declined to testify. The hearing pushed the Hawley–Durbin bill ending forced arbitration for child sexual exploitation claims (35% of Roblox's age-checked DAU are under 13). Relevant to anyone building platforms with minors. Source: WIRED

ID.me terms required for IRS sign-in​

Taxpayers using ID.me for IRS services accept ID.me's own ToS — forced arbitration (30-day opt-out) and data-use/marketing clauses — even though government-run Login.gov works too. Senators Wyden and Warren asked Treasury why ID.me (which also replaced TreasuryDirect login Oct 28) is used at all; IRS Direct Pay needs no sign-in. Source: Consumer Rights Wiki

Engineering Vitals in the Age of AI (Octopus)​

Andrew Best argues against both token-counting and pure "just measure value" camps: outputs are the proxy for value via the value-discovery loop, and engineering leaders should track throughput/stability "vitals" (e.g., merged PRs, incident time) to answer whether AI actually improves software delivery. A pragmatic counterpoint to the Harvard findings above. Source: Octopus blog

This Week in Spring — Nov 18, 2026​

Josh Long's roundup: Spring AI 2.1.0-RC2, Spring Boot 4.2.0-RC2, Spring Cloud 2026.0.0-RC1 "Paddington" released; Spring for Apache Pulsar gets a new home at the ASF — and the top item is "UPDATE YOUR JVMs!" for Java4Shell (see P0). Source: Spring Blog

Vapi vs Retell AI vs LiveKit: voice AI platform comparison​

DZone comparison of the three leading voice-agent platforms across architecture, latency, pricing, and developer experience — useful shortlist material for voice-agent build-vs-assemble decisions. Source: DZone

JetBrains ReSharper C++ 2026.3 released​

The Visual Studio C++ extension ships a new "Class Layout" tool window and improved format-string analysis. Source: Developpez
